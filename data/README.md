The thesis uses confidential, municipality-level data from Lithuania's State Social
Insurance Fund Board (SoDra), provided under a data-use agreement. It is not included
in this repository.

The three `.dta` files here are synthetic. They have the same structure as the
original files, so every script runs unchanged, but all values are generated from
arbitrary rules and are not based on the real data. Results produced from them do
not reproduce the thesis estimates; the published results are in `thesis_results/`.
